# Playbook

What has worked on this account, and what the editor keeps correcting. The app shows
this file to every studio session; where it disagrees with the voice guide, this file
wins. The panel's Studio page proposes changes to it from the account's X results; a
human approves each change.

Status: seeded by hand from the first three studio-style pieces (Merck SPR2015,
SMMT catalyst map, next-gen CTLA-4; Oct 2026). Their X results so far are too small to
read anything into (1 to 3 likes each), so everything below is editorial judgement,
not data yet.

## Openings
- The two strongest openings so far set two facts against each other ("paid $400
  million for a drug never tested in a human" next to "walked away from a $30 billion
  deal for the leader") or put the one number that matters up front ("nearly doubled
  median survival, 18.5 vs 10.0 months"). Both work inside the first 280 characters.
- Name the stakes and the clock when the piece is about catalysts ("the next ~9
  months will define much of its story").

## Substance the editor values
- A clear view, labelled as a view ("my read", "I'd take those numbers with a big
  grain of salt"), backed by numbers.
- The reality check: the small n, the stage-1-not-pivotal caveat, the forecasts that
  disagree with each other, the competitor already marketing against the asset.
- The read on structure in deals (share of value upfront, options or none, how fast
  it closed) and the comparison that makes a price meaningful.
- Signposts with dates at the end.

## Mistakes caught in fact-checks (do not repeat)
- A page's retrieval date shown as news of that date. Check when a thing actually
  happened.
- "Analysts have flagged" when one analyst did. Name the source.
- A PDUFA goal date written as a decision date.
- "First revenue" for a company that had licence revenue before; say "first product
  revenue".
- A competitor's drug presented as same-line when its label is a line later.
- Percent shares that add up to more than their parent category.
- Sales figures from memory (Tagrisso "~$6B" when it sold $7.25B). Look them up.
- A forecast attributed to "forecasters" when one firm made it.
- Interim analyses: "didn't stop early" understates a missed interim bar; say what
  happened.

## Format
- Plain text that pastes cleanly into X: ALL-CAPS section headers, • bullets,
  numbered lists, no markdown.
- 4:5 cards, dark house style; the headline states the finding.
- End the body with a question specialists can answer when it fits ("Which next-gen
  CTLA-4 are you watching?"). A reply is worth more than a like.
- "Not investment advice." then sources in words, then tags.

## Still to learn (the feedback loop fills these in)
- Long post or thread of long posts?
- How many cards, and which card types get the most engagement?
- Emoji: none, a few as section markers, or one in the hook?
- Best posting times for this audience.
- Which angles earn replies and follows rather than likes.
